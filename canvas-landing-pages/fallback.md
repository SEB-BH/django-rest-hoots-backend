## About

Build a PostgreSQL-backed Django REST API that connects to an existing React application. This module introduces only the Python and Django concepts needed to create an authenticated CRUD MVP.

## Content

| Day | Lesson | Time | Skill |
| --- | --- | ---: | --- |
| 1 | [Django and Python Orientation](../django-and-python-orientation/README.md) | 30 min | Relate Express concepts to Django and read the Python syntax used in the project. |
| 1 | [Project and Database Setup](../project-and-database-setup/README.md) | 60 min | Create a virtual environment, Django project, app, and PostgreSQL connection. |
| 1 | [Models and Migrations](../models-and-migrations/README.md) | 75 min | Define related models and create database tables with migrations. |
| 1 | [Serializers and API Shapes](../serializers-and-api-shapes/README.md) | 60 min | Translate Django model instances into the JSON expected by React. |
| 2 | [JWT Authentication](../jwt-authentication/README.md) | 75 min | Create sign-up/sign-in endpoints and protect the API with Bearer tokens. |
| 2 | [Hoot CRUD](../hoot-crud/README.md) | 75 min | Build explicit list, create, show, update, and delete handlers. |
| 2 | [Comments and Ownership](../comments-and-ownership/README.md) | 75 min | Build nested comment routes and enforce author-only changes. |
| 2 | [Connect the React Frontend](../connect-the-react-frontend/README.md) | 45 min | Configure CORS and connect Vite to Django. |
| 2 | [Integration Lab](../integration-lab/README.md) | 60 min | Verify the complete user flow and diagnose common integration errors. |
